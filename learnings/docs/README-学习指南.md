## 学习路径

### 快速入门（2-3 小时）

如果您只有有限时间，按以下顺序阅读：

1. 01-AI-Agent基础概念
2. 02-Gemini-CLI项目概览
3. 03-本地开发快速开始

### 深度理解（1-2 天）

想要深入了解项目架构：

1. 完成快速入门
2. 04-项目架构详解
3. 05-包间通信机制
4. 09-Agentic-Loop详解

### 工具开发（2-3 天）

想要开发自定义工具：

1. 完成深度理解
2. 13-工具系统架构
3. 17-自定义工具开发
4. 18-工具执行与调度

### 全面掌握（1-2 周）

想要完全掌握整个项目：

1. 按顺序阅读所有文档
2. 在代码库中实践概念
3. 尝试实现新功能

## 文档使用建议

### 📖 阅读技巧

- **⭐️ 标记的文档** - 新手必读，优先学习
- **代码示例** - 关注代码模式和最佳实践
- **流程图** - 理解系统的执行流程
- **交叉引用** - 跳转到相关文档深入理解

### 🔍 实践建议

- 克隆项目并在本地运行
- 修改代码并观察效果
- 编写测试验证理解
- 尝试实现小功能

### 🤝 获取帮助

- 查看项目的 CONTRIBUTING.md
- 阅读项目 issue 了解常见问题
- 加入社区讨论
