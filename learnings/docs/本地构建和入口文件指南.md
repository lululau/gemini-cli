# Gemini CLI 本地构建和入口文件指南

## 项目本地构建指南

### 环境要求

- **Node.js**: 20.0.0 或更高版本
- **操作系统**: macOS, Linux, 或 Windows
- **包管理器**: npm 或 yarn

### 完整构建流程

#### 1. 克隆项目

```bash
git clone https://github.com/google-gemini/gemini-cli.git
cd gemini-cli
```

#### 2. 安装依赖

```bash
npm install
```

#### 3. 生成版本信息

```bash
npm run generate
```

#### 4. 构建所有包

```bash
npm run build
```

或者运行包含沙箱的完整构建：

```bash
npm run build:all
```

#### 5. 构建可分发包（Bundle）

```bash
npm run bundle
```

### 构建命令详解

#### 主要构建命令

- **`npm run build`**: 标准构建，构建所有工作空间包
- **`npm run build:packages`**: 仅构建包（不包含沙箱）
- **`npm run build:sandbox`**: 构建沙箱环境
- **`npm run build:vscode`**: 构建 VS Code 扩展
- **`npm run build:all`**: 完整构建（包含沙箱和 VS Code 扩展）
- **`npm run bundle`**: 生成可分发包

#### 开发命令

- **`npm run start`**: 启动开发服务器
- **`npm run debug`**: 以调试模式启动
- **`npm run build-and-start`**: 构建后立即启动

#### 测试命令

- **`npm run test`**: 运行所有测试
- **`npm run test:integration:all`**: 运行所有集成测试
- **`npm run test:integration:sandbox:none`**: 无沙箱集成测试
- **`npm run test:integration:sandbox:docker`**: Docker 沙箱集成测试

#### 代码质量命令

- **`npm run lint`**: 代码检查
- **`npm run format`**: 代码格式化
- **`npm run typecheck`**: 类型检查
- **`npm run preflight`**: 完整预提交检查

### 构建过程

#### 第一阶段：包构建

1. 检查并安装 `node_modules`
2. 生成 Git 提交信息文件
3. 使用 TypeScript 编译所有工作空间包
4. 构建沙箱容器镜像（如果启用）

#### 第二阶段：打包（Bundling）

1. 使用 ESBuild 创建可执行文件
2. 入口点：`packages/cli/index.ts`
3. 输出文件：`bundle/gemini.js`
4. 支持 WASM 插件和 Node.js 原生模块

#### 构建产物

- **`bundle/gemini.js`**: 主可执行文件
- **`packages/*/dist/`**: 各包的编译输出
- **`bundle/sandbox-*.sb`**: macOS 沙箱配置文件

## 项目入口文件详解

### 主入口文件

#### 1. CLI 入口：`packages/cli/index.ts`

这是命令行工具的主入口点，包含：

- Shebang `#!/usr/bin/env node` 用于直接执行
- 导入并调用 `main()` 函数
- 全局错误处理和退出码管理
- 颜色输出支持

```typescript
#!/usr/bin/env node

import './src/gemini.js';
import { main } from './src/gemini.js';
import { debugLogger, FatalError } from '@google/gemini-cli-core';

main().catch((error) => {
  // 错误处理逻辑
});
```

#### 2. 核心逻辑：`packages/cli/src/gemini.js`

实际的 CLI 核心逻辑，包含：

- 命令行参数解析
- 配置管理
- 用户界面渲染（使用 Ink）
- 与核心包的通信

### 包结构入口

#### CLI 包：`packages/cli/`

- **主入口**: `packages/cli/index.ts`
- **可执行文件**: `packages/cli/dist/index.js`（构建后）
- **NPM bin**: `gemini`

#### 核心包：`packages/core/`

- **主入口**: `packages/core/dist/index.js`（构建后）
- **功能**: API 客户端、工具管理、状态管理

### 构建后的可执行文件

#### 分发版本：`bundle/gemini.js`

这是最终的分发版本，由 ESBuild 创建：

- 包含所有依赖的完整包
- 支持 Node.js 20+
- 包含 WASM 支持
- 包含 Node.js 原生模块支持

### 开发 vs 生产环境

#### 开发环境

- 入口：`packages/cli/index.ts`
- 运行：`npm run start`
- 支持热重载和调试

#### 生产环境

- 入口：`bundle/gemini.js`
- 安装：`npm install -g @google/gemini-cli`
- 命令：`gemini`

### 配置和环境变量

#### 重要环境变量

- **`CLI_VERSION`**: 版本号（在构建时注入）
- **`BUILD_SANDBOX`**: 是否构建沙箱环境
- **`GEMINI_API_KEY`**: Gemini API 密钥
- **`GOOGLE_GENAI_USE_VERTEXAI`**: 使用 Vertex AI

#### 配置文件位置

- 项目设置：`~/.gemini/settings.json`
- 项目上下文：`GEMINI.md`（项目根目录）

## 快速开始

### 克隆并运行

```bash
git clone https://github.com/google-gemini/gemini-cli.git
cd gemini-cli
npm install
npm run build
npm run start
```

### 直接使用 bundle

```bash
npm run bundle
node bundle/gemini.js --help
```

### 安装为全局命令

```bash
npm run build
npm pack
npm install -g google-gemini-cli-*.tgz
gemini --help
```

## 故障排除

### 常见问题

1. **Node.js 版本不兼容**: 确保使用 Node.js 20+
2. **依赖安装失败**: 尝试 `npm run clean && npm install`
3. **构建失败**: 检查 TypeScript 语法和依赖版本
4. **沙箱构建失败**: 检查 Docker 安装状态

### 调试技巧

- 使用 `npm run debug` 进行调试
- 设置 `DEBUG=1` 环境变量获取详细日志
- 检查 `bundle/esbuild.json` 了解构建详情
