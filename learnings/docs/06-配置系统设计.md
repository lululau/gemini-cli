# 配置系统设计

## 配置体系概览

```
环境变量 (优先级最高)
    ↓
CLI 参数 (--flag)
    ↓
项目配置 (GEMINI.md)
    ↓
用户设置 (~/.gemini/settings.json)
    ↓
默认值 (优先级最低)
```

## Settings 系统

### 文件位置

- **用户设置**: `~/.gemini/settings.json`
- **系统设置**: `/etc/gemini/settings.json` (Linux)

### Settings 结构

```typescript
interface Settings {
  security: {
    auth: {
      selectedType?: AuthType;
      useExternal?: boolean;
    };
  };
  ui: {
    theme?: string;
    renderMarkdown?: boolean;
    customThemes?: Record<string, ThemeConfig>;
  };
  models: {
    default?: string;
    maxTokens?: number;
  };
  advanced: {
    dnsResolutionOrder?: string;
    proxy?: string;
  };
  extensions?: {
    enabled?: string[];
    disabled?: string[];
  };
}
```

### 加载流程

```typescript
// packages/cli/src/config/settings.ts
export function loadSettings(): LoadedSettings {
  // 1. 读取用户设置文件
  const userSettings = readJsonFile(userSettingsPath);

  // 2. 合并环境变量
  const merged = mergeWithEnv(userSettings);

  // 3. 返回可修改的 Settings 对象
  return {
    user: userSettings,
    system: systemSettings,
    merged: merged,
    setValue: (scope, key, value) => {...},
    deleteValue: (scope, key) => {...},
  };
}
```

### Config 初始化

```typescript
// packages/core/src/config/config.ts
export class Config {
  constructor(params: ConfigParameters) {
    // 存储所有配置参数

  async initialize(): Promise<void> {
    // 1. 初始化工具注册表

    // 4. 其他初始化
  }
```

## CLI 配置加载

### 参数解析

```bash
gemini [选项] [输入]

选项：
  --model <model>              指定模型
  --debug                      启用调试
  --allowed-tools <tools>      允许的工具
  --no-color                   禁用颜色
  --sandbox <type>             沙箱类型
  --mcp-server <url>           MCP 服务器
  --interactive, -i            交互模式
  --prompt <text>              一次性提示
```

### 参数验证

```typescript
// packages/cli/src/config/config.ts
async function parseArguments(settings: Settings): Promise<CliArgs> {
  const argv = yargs()
    .option('model', { describe: '模型', type: 'string' })
    .option('debug', { describe: '调试模式', type: 'boolean' })
    .option('prompt', { describe: '输入提示', type: 'string' })
    // ... 更多选项
    .parse();

  // 验证参数
  validateModel(argv.model);
  validateTools(argv.allowedTools);

  return argv;
}
```

### 支持的认证方式

```typescript
enum AuthType {
```

### 认证流程

```
选择认证方式
    ↓
获取凭证（OAuth / API Key / Service Account）
    ↓
保存到 Settings
    ↓
创建 ContentGenerator
    ↓
验证凭证有效性
    ↓
准备 API 调用
```

## 最佳实践

1. **分层配置** - 使用多个配置源
2. **验证配置** - 启动时验证所有配置
3. **默认值** - 提供合理的默认值
4. **文档化** - 记录所有配置选项
5. **向后兼容** - 支持旧配置格式的迁移
