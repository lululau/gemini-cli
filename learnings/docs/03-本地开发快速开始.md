# 本地开发快速开始

## 前置要求

在开始之前，请确保您的系统满足以下要求：

- **Node.js**: 20.0.0 或更高版本（推荐 20 LTS）
- **npm**: 版本 9.0 或更高
- **操作系统**: macOS, Linux, 或 Windows（WSL 推荐）
- **Git**: 用于克隆仓库

## 环境检查

```bash
# 检查 Node.js 版本
node --version  # 应显示 v20.0.0 或更高

# 检查 npm 版本
npm --version   # 应显示 9.0 或更高

# 检查 Git
git --version   # 应显示版本信息
```

## 第一步：克隆并进入项目

```bash
# 克隆官方仓库
git clone https://github.com/google-gemini/gemini-cli.git
cd gemini-cli

# 或者克隆您的分支
git clone https://github.com/YOUR_USERNAME/gemini-cli.git
cd gemini-cli
```

## 第二步：安装依赖

```bash
# 安装所有依赖
# 这会自动安装所有 workspace 包的依赖
npm install

# 如果遇到问题，尝试清理缓存
npm cache clean --force
rm -rf node_modules
npm install
```

## 第三步：生成版本信息

```bash
# 生成 Git 提交信息和版本文件
npm run generate
```

这会创建以下文件：

- `packages/cli/src/generated/git-commit.ts`
- `packages/core/src/generated/git-commit.ts`

## 第四步：完整构建

```bash
# 构建所有 workspace 包
npm run build

# 或者只构建特定包
npm run build -w @google/gemini-cli-core
npm run build -w @google/gemini-cli
```

## 第五步：本地运行

### 方式一：直接运行源代码

```bash
# 进入 CLI 包目录
cd packages/cli

# 运行（开发模式）
npx ts-node index.ts "你的问题"

# 或使用开发脚本
cd ../..
npm run start
```

### 方式二：使用 npm 脚本

```bash
# 开发模式运行
npm run start

# 调试模式运行
npm run debug

# 构建后运行
npm run bundle
node bundle/gemini.js "你的问题"
```

### 方式三：交互式模式

```bash
# 启动交互式 CLI
npm run start

# 在提示符处输入您的问题
> 你好，请帮我写一个 Node.js 的 HTTP 服务器
```

## 常用开发命令

### 构建相关

```bash
# 完整构建（所有包）
npm run build

# 仅构建包（不包括沙箱）
npm run build:packages

# 构建特定包
npm run build -w @google/gemini-cli

# 生成打包文件
npm run bundle
```

### 测试相关

```bash
# 运行所有测试
npm run test

# 运行特定包的测试
npm run test -w @google/gemini-cli-core

# 运行集成测试
npm run test:integration:all

# 运行单个测试文件
vitest run path/to/test.test.ts

# 监视模式运行测试
npm run test -- --watch
```

### 代码质量

```bash
# 代码检查
npm run lint

# 自动修复 lint 问题
npm run lint:fix

# 代码格式化
npm run format

# TypeScript 类型检查
npm run typecheck

# 完整检查（推荐提交前运行）
npm run preflight
```

### 调试

```bash
# 以调试模式启动
npm run debug

# 然后在浏览器中打开 chrome://inspect
# 或在 VS Code 中连接调试器
```

## 开发工作流示例

### 场景一：添加新功能

```bash
# 1. 创建新分支
git checkout -b feature/my-feature

# 2. 编辑代码
# 修改相关文件...

# 3. 本地测试
npm run start  # 或 npm run test

# 4. 代码检查
npm run lint:fix
npm run format

# 5. 类型检查
npm run typecheck

# 6. 完整构建和测试
npm run preflight

# 7. 提交
git add .
git commit -m "feat: add my feature"
git push origin feature/my-feature

# 8. 创建 PR
```

### 场景二：修复 Bug

```bash
# 1. 找到 Bug 对应的测试文件
# packages/*/src/**/*.test.ts

# 2. 运行失败的测试
npm run test -- path/to/failing.test.ts

# 3. 修复代码
# 编辑相关源文件...

# 4. 验证测试通过
npm run test -- path/to/failing.test.ts

# 5. 确保所有测试通过
npm run preflight
```

### 场景三：调试特定功能

```bash
# 1. 在代码中添加 console.log 或使用调试器
// 在 packages/core/src/tools/shell.ts 中
console.log('执行命令:', command);

# 2. 启动调试模式
npm run debug

# 3. 或者使用开发脚本并输出详细日志
DEBUG=* npm run start

# 4. 测试功能
# 在交互式提示符中输入测试输入...
```

## 配置和自定义

### 本地设置文件

创建 `~/.gemini/settings.json` 来自定义配置：

```json
{
  "security": {
    "auth": {
      "selectedType": "GOOGLE_AUTH"
    }
  },
  "ui": {
    "theme": "dracula",
    "renderMarkdown": true
  },
  "advanced": {
    "dnsResolutionOrder": "ipv4first"
  }
}
```

### 项目级配置

在项目根目录创建 `GEMINI.md` 来提供项目上下文：

```markdown
# 项目说明

## 项目概述

这是一个示例项目，用于演示 Gemini CLI 的功能。

## 关键信息

- 语言：TypeScript
- 框架：React + Ink
- 目标：创建 AI 助手的 CLI 工具

## 文件结构

- `src/` - 源代码
- `dist/` - 编译输出
- `tests/` - 测试文件

## 常见任务

- 构建：`npm run build`
- 测试：`npm run test`
```

## 常见问题

### Q: npm install 失败

**A:** 尝试以下步骤：

```bash
npm cache clean --force
rm -rf node_modules package-lock.json
npm install
```

### Q: 构建失败，提示 TypeScript 错误

**A:** 运行类型检查：

```bash
npm run typecheck

# 或针对特定包
npm run typecheck -w @google/gemini-cli-core
```

### Q: 测试不通过

**A:** 检查是否有不支持的功能：

```bash
# 运行特定测试
npm run test -- path/to/test.test.ts

# 以监视模式运行
npm run test -- --watch
```

### Q: 启动时出现权限错误

**A:** 确保有正确的权限：

```bash
chmod +x node_modules/.bin/*
npm run start
```

### Q: 缺少 Gemini API 密钥错误

**A:** 设置 API 密钥：

```bash
export GEMINI_API_KEY="your-api-key"

# 或使用交互式认证
gemini auth
```
