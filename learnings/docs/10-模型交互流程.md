# 模型交互流程

## API 调用流程

```
构造请求
    ├─ 系统提示
    ├─ 历史记录
    ├─ 工具定义
    └─ 用户消息
    ↓
调用 Gemini API
    ├─ sendMessageStream()
    └─ 返回流
    ↓
处理响应
    ├─ 流式接收 chunks
    ├─ 解析 delta
    └─ 生成事件
    ↓
错误处理
    ├─ 重试
    ├─ 降级
    └─ 报错
```

## 流式处理

```typescript
const stream = await client.generateContentStream(request);

for await (const response of stream) {
  // 处理每个 chunk
  yield parseResponse(response);
}
```

## 重试机制

- 指数退避
- 最多 3 次重试
- 可配置的超时
