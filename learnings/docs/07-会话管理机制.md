# 会话管理机制

## 会话生命周期

```
创建会话
    ↓
初始化会话状态
    ├─ sessionId 生成
    ├─ 创建时间戳
    └─ 初始化历史记录
    ↓
活跃状态
    ├─ 记录交互
    ├─ 保存检查点
    └─ 更新活动时间
    ↓
会话结束
    ├─ 保存最终状态
    ├─ 清理临时资源
    └─ 记录会话元数据
    ↓
会话清理
    ├─ 删除过期会话
    ├─ 清理临时文件
    └─ 更新统计数据
```

```
~/.gemini/sessions/
├── {sessionId}/

│   ├── history.json         # 完整历史
```

### 恢复流程

```typescript
async function recoverSession(sessionId: string): Promise<void> {
  // 1. 加载检查点
  const checkpoint = await loadCheckpoint(sessionId);

  // 2. 恢复历史记录
  const history = await restoreHistory(checkpoint);

  // 3. 恢复工作状态
  await restoreToolStates(checkpoint);

  // 4. 验证一致性
  await validateConsistency(checkpoint);
}
```
